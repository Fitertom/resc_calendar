# Glint Calendar

Календарь, который открывается по клику на часы в панели задач Windows 11. Только календарь: без уведомлений, без новостей, без лишнего.

Окно в стиле ExplorerBlurMica: размытие того, что сзади, минимализм, а выезжает оно той же анимацией, что и меню быстрых настроек Windows. Написан на Rust прямо на Win32 и GDI, без UI-фреймворков. Это ответвление [Glint](https://github.com/Fitertom/resc_glint).

## Что умеет

| Действие | Что происходит |
|---|---|
| Клик по часам | Открыть / закрыть календарь |
| ПКМ по дню | Отметить день красным кружком; ещё раз ПКМ снимает отметку |
| СКМ по дню | Написать заметку (Enter сохраняет, Esc отменяет) |
| СКМ по дню с заметкой | Удалить заметку |
| Навести на день с заметкой | Показать заметку |
| Колесо, PgUp / PgDn | Листать месяцы |
| Клик по названию месяца, Home | Вернуться к сегодняшнему дню |
| Увести мышь с календаря, Esc | Закрыть |

Сегодняшний день выделен кругом, дни с заметками помечены точкой.

## Требования

- Windows 11 (проверено на 24H2, build 26100). Панель задач Windows 10 устроена иначе, там не работает.
- Для сборки: [Rust](https://rustup.rs) (stable, toolchain `x86_64-pc-windows-msvc`) и Visual Studio Build Tools с компонентом «Разработка классических приложений на C++».

## Установка

### Готовая сборка

1. Скачать `glint-calendar-0.1.0.zip` со страницы [Releases](https://github.com/Fitertom/resc_calendar/releases/latest) и распаковать в любую папку. `glint-calendar.exe` и `glint_calendar_tap.dll` должны лежать рядом.
2. В этой папке выполнить:

   ```powershell
   .\glint-calendar.exe --install
   ```

   Что делает установка, описано в шаге 2 ниже. После неё папку с распакованным архивом можно удалить.

3. Кликнуть по часам.

Exe не подписан, поэтому SmartScreen может предупредить при первом запуске.

### Сборка из исходников

1. Собрать приложение и DLL, которая ловит клик по часам:

   ```powershell
   git clone https://github.com/Fitertom/resc_calendar.git
   cd resc_calendar
   cargo build --release
   cd tap
   cargo build --release --target-dir ../target
   cd ..
   ```

   В `target\release` появятся `glint-calendar.exe` и `glint_calendar_tap.dll`. Они должны лежать рядом.

2. Установить:

   ```powershell
   .\target\release\glint-calendar.exe --install
   ```

   Программа копируется в `%LOCALAPPDATA%\Programs\Glint Calendar`, добавляет ярлык в меню «Пуск» и автозапуск, регистрирует удаление в «Приложениях» и сразу запускается. Права администратора не нужны.

3. Кликнуть по часам.

### Убрать системное окно уведомлений (по желанию)

Клик по часам у Windows открывает ещё и свою панель уведомлений с календарём, и она откроется вместе с этим календарём. Чтобы осталась только Glint Calendar, системную панель можно отключить (для текущего пользователя), а затем перезапустить проводник или выйти из системы:

```powershell
New-Item -Path HKCU:\Software\Policies\Microsoft\Windows\Explorer -Force | Out-Null
Set-ItemProperty -Path HKCU:\Software\Policies\Microsoft\Windows\Explorer -Name DisableNotificationCenter -Value 1 -Type DWord
```

Вернуть: удалить значение `DisableNotificationCenter`.

## Удаление

Через «Параметры → Приложения → Установленные приложения → Glint Calendar» или командой:

```powershell
& "$env:LOCALAPPDATA\Programs\Glint Calendar\glint-calendar.exe" --uninstall
```

Заметки при этом остаются в `%APPDATA%\Glint Calendar`.

## Команды

| Аргумент | Действие |
|---|---|
| без аргументов | Открыть / закрыть календарь (запускает фоновый процесс, если его нет) |
| `--background` | Запустить фоновый процесс без окна (так стартует автозапуск) |
| `--install` / `--uninstall` | Установить / удалить |
| `--quit` | Завершить фоновый процесс |

## Настройки

Файл `glint-calendar.ini` рядом с exe, создаётся при первом запуске. Изменения применяются после перезапуска (`--quit`, потом запуск снова).

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `tint` | `2e2e2e` | Цвет подложки поверх размытия, RRGGBB |
| `tint_alpha` | `120` | Плотность подложки, 0..255 (подобрано под проводник с ExplorerBlurMica) |
| `weekends` | `true` | Выходные другим цветом |

Заметки и отметки хранятся в `%APPDATA%\Glint Calendar\notes.txt`, по строке на день: `2026-11-05<TAB>mark` или `2026-11-05<TAB>note<TAB>текст`. Файл можно править руками и бэкапить.

## Как это работает

Панель задач Windows 11 сделана на XAML внутри `explorer.exe`, и реестром на клик по часам не повесишь свою программу. Поэтому:

- `glint-calendar.exe` держит в фоне скрытое окно календаря.
- При старте он подгружает в `explorer.exe` маленькую `glint_calendar_tap.dll` через штатный механизм XAML-диагностики (`InitializeXamlDiagnosticsEx`, им же пользуется Visual Studio).
- DLL находит в дереве панели задач кнопку часов, подписывается на её клик и при клике шлёт сообщение окну календаря. Больше она ничего не делает.
- Если проводник перезапустился, календарь замечает это и подгружает DLL заново.

| Папка / файл | Что там |
|---|---|
| `src/main.rs` | Аргументы, запуск, фоновый процесс |
| `src/app.rs` | Состояние, мышь, клавиатура, анимация |
| `src/ui.rs` | Отрисовка через GDI, альфа для размытия |
| `src/win.rs` | Окна Win32, размытие (accent policy), DWM |
| `src/cal.rs` | Даты, названия месяцев и дней |
| `src/notes.rs` | Файл заметок |
| `src/inject.rs` | Подгрузка DLL в проводник |
| `src/install.rs` | Установка, автозапуск, удаление |
| `tap/` | DLL для проводника; `tap/gen` генерирует привязки XAML из системного `Windows.UI.Xaml.winmd` |

## Известные моменты

- Антивирусы (например, Malwarebytes) могут ругаться на подгрузку DLL в проводник. Это ожидаемо для такого способа; DLL видна целиком в `tap/src/lib.rs`.
- Крупное обновление Windows может поменять устройство панели задач, и клик перестанет ловиться. Журнал DLL пишется в `%TEMP%\glint_calendar_tap.txt`.
- Интерфейс на русском.
